### Selected work

**[GoTogether Trip Planner](https://github.com/vulkanCommand/gotogether)** · [App Store](https://apps.apple.com/us/app/gotogether-trip-planner/id6767730138)  
A group trip-planning app released on the App Store. Shared itineraries, invites, expenses, notifications, and trip memories, backed by authenticated Go APIs, PostgreSQL, and cloud media storage with a production release pipeline.  
<sub>React Native · Expo · Go · PostgreSQL · Firebase · Google Cloud</sub>

**[xCommand Cloud](https://github.com/vulkanCommand/xcommand-n8n-rental)**  
On-demand automation infrastructure. Provisions isolated n8n workspaces behind dedicated URLs in seconds, manages container lifecycle and capacity, monitors platform health, and reclaims expired resources automatically.  
<sub>Docker · Traefik · FastAPI · n8n · Prometheus</sub>

**[Env Guardian](https://github.com/vulkanCommand/env-guardian)**  
A Go CLI and VS Code workflow that validates environment configuration before deployment: detects code/config drift and potential secret leaks, supports encrypted env files, and emits CI-ready JSON. Distributed via Homebrew.  
<sub>Go · CLI · VS Code · CI · Security</sub>

**[RoomCast](https://github.com/vulkanCommand/RoomCast)**  
Private two-person watch rooms with direct screen and voice streaming. Firebase handles identity and signaling; WebRTC carries media peer to peer, with no stored video, chat, or recordings.  
<sub>React · TypeScript · WebRTC · Firebase</sub>
